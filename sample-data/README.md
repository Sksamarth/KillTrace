# Sample data

No sample logs or datasets are included. No synthetic incident events have been generated.

This directory is reserved for future authorized, appropriately sanitized examples after formats and evaluation requirements are finalized. Large datasets should remain outside Git; document their provenance and retrieval instructions when approved for use.

Never commit credentials, tokens, personal information, confidential telemetry, or real incident logs without authorization and review. The root ignore rules exclude this directory's contents except Markdown documentation.

The 15 GB, 30 GB, and 50 GB dataset sizes are future processing goals. They do not describe bundled data or existing processing capability.
